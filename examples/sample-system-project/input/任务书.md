# 毕业设计任务书(虚构示例材料)

> 本文件为 PaperWriter 的演示材料,人物、学校、题目均为虚构。
> 用途:把本目录内容复制到你的项目 `input/` 后,对智能体说"写论文",即可体验**系统先行**工作流(先做出可运行系统,再基于真实运行结果写论文)。

## 毕设题目
基于 Python(Flask)的学生成绩管理系统的设计与实现

## 交付物
1. 可运行的 Web 系统(含源码;须支持一键启动、演示数据一键重置;交付对象为非技术用户,附部署说明);
2. 毕业论文一篇,12000 字左右。

## 论文结构要求(指导老师)
1. 绪论(背景意义、国内外现状);
2. 相关技术介绍;
3. 系统需求分析(功能需求用例、非功能需求);
4. 系统总体设计(架构、功能模块、数据库设计);
5. 系统详细实现(关键功能实现,须有真实界面截图);
6. 系统测试(测试用例表、功能与回归测试结果);
7. 总结与展望;
8. 参考文献不少于 15 篇,近 5 年为主,GB/T 7714-2015。

## 技术约束
- 后端 Python + Flask;数据存储用 SQLite(免安装,便于演示);
- 不要求 Docker;
- 三种角色:管理员(管理课程与学生)、教师(录入与发布成绩)、学生(查询成绩);
- 成绩查询支持按学期/课程筛选,成绩发布前学生不可见。

## 其他说明
- 暂无现成文献清单(走自动检索);
- 无学校格式模板(使用默认学术排版)。
