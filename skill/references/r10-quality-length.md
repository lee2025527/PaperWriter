# r10 质量优化与字数达标

对应流水线步骤 10。对 `正文_合并_v1.md` 做"表达优化 + 字数核验 + 必要扩写",产出 `output/work/正文_终审优化版.md` 与 `output/work/正文_字数达标版.md`。全程加载 `output/work/prompt.md`。

## 1) 质量优化(五维逐章审视)

1. 语言逻辑:句子通顺、指代清晰、概念一致;
2. 前后贯通:"研究问题 → 方法 → 结果/讨论 → 结论"闭环,章节衔接自然;
3. 表达净化:删空泛套话、重复表述、无信息增量段落;
4. AI 痕迹:消除机械列点、模板句、黑名单词(writing-rules §4.2);
5. 事实一致:不引入新数据/新结论,术语与变量统一。

修改强约束:不改变既定结构(结构性错误用"【结构调整建议】"标注,不擅动);每一处优化必须有信息增量。

输出 `output/work/正文_终审优化版.md`。

## 2) 字数核验

- 统计字数(按需求单口径,一般指正文字符数);
- 目标优先级:需求单 → thesis_writing_plan → 问用户;
- 达标 → 直接转存 `正文_字数达标版.md`。

## 3) 必要扩写(仅字数不足时)

扩写优先级:① 方法细化(研究设计、指标定义、流程细节);② 论点与既有文献更明确对齐;③ 讨论深化(局限、边界、可推广性);④ 案例/数据补强(仅有真实来源时)。
约束:紧扣主题、结构一致、不新增不可验证结论、不编造数据。

## 4) 扩写后引用复检(必做)

扩写可能引入/移动引用 → 重新执行 r09 §二 引用治理算法,确保正文引用与文末列表一一对应,再输出 `output/work/正文_字数达标版.md`。

## 守门

字数达标(目标区间内);黑名单词扫描为 0;引用复检通过。
