# r07 写作计划(分批)

对应流水线步骤 7。产出 `output/work/thesis_writing_plan.md`,定义"怎么写正文":批次怎么拆、每批写什么、字数怎么分、按什么顺序合并。基于 `$SKILL/templates/thesis_writing_plan_template.md` 生成。

## 输入

`需求单.md`(总字数/约束)、`prompt.md`、`文献综述.md`、`论文大纲.md`、`文献详细列表.md`、`案例与数据文档.md`;系统先行项目加规划与测试报告。

## 必须包含

### 1) 字数预算
总字数与允许浮动区间;每章分配(需求单有分配则从之,无则按结构默认)。

### 2) 批次拆分
- 正文批次:按章节拆,覆盖全部正文;每批:覆盖章节 + 目标字数 + 核心内容 + 要点策略;
- 单批不宜超过模型单次安全输出长度,宁多批勿超批;
- **摘要批次必须是最后一个批次**:正文全部完成后执行;中文摘要(约300字)+中文关键词(3–5个)+英文摘要(约250词)+英文关键词(3–5个);经典四段式:背景与目的→方法→结果→结论;摘要只写正文中已有的内容。

### 3) 机器可读批次清单(Batch Manifest,必须)
计划中包含可被 `yaml.safe_load()` 解析的 YAML 区块:
```yaml
batch_manifest_version: 1
batches:
  - index: 1
    name: 第一章 绪论
    target_word_count: 1500
    min_word_count: 1200
  # ...最后一个批次为中英文摘要
```
批次守护脚本据此做"是否写完"的硬校验,`index`/`name`/`target_word_count`/`min_word_count` 四字段每批必备。

### 4) 合并输出顺序(固定)
1. 中文摘要+关键词 → 2. 英文摘要+关键词 → 3. 目录占位 `[TOC]`(内容留空,Word 生成) → 4. 正文第一章…第 N 章 → 5. 参考文献 → 6. 致谢(可选附录)

## 守门

- 各批 `target_word_count` 总和 = 目标总字数(误差 ≤5%);
- 批次覆盖大纲全部章节,无遗漏(摘要批次在最后);
- YAML 清单可解析:`python3 -c "import yaml,sys;..."` 或直接由下一步 verify_batches 校验。
