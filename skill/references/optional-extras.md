# optional-extras 支线能力(本期未随包发布)

PaperWriter 首版聚焦"论文初稿主线 + 系统先行分支"。以下能力已在源工作流中验证过,计划在后续版本作为**可选支线**提供;当前版本用户明确提出时,说明"该支线将在后续版本提供",并给出可用的替代建议。

| 支线 | 说明 | 状态 |
|---|---|---|
| 论文英文化 | 中文学位论文翻译为学术英文 + AI 表达检查 + 字数报告 | 计划 v1.1 |
| 英文降 AI 检出率 | 对英文论文 docx 做 Turnitin AI 率深度优化(保持排版/图表/公式不变) | 计划 v1.1 |
| 开题报告 | 基于客户诉求+综述生成开题报告 | 计划 v1.1 |
| 对标论文分析 | 找一篇对标论文,解析其结构与写作标准供参照 | 计划 v1.1 |
| 修订清单 | 对照要求生成论文修改清单 | 计划 v1.1 |
| 模板精确填充 | 将内容精确填充到客户 Word 模板,格式 100% 一致 | 计划 v1.1 |

主线的"套用学校模板"能力(`--template`)已包含在本版 r09/r12 中,不属于支线。
