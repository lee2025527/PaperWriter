# r03 文献综述

对应流水线步骤 3。产出 `output/work/文献综述.md`。开始前必须加载 `output/work/prompt.md`。

## 输入

1. `output/work/prompt.md`(写作入口与约束)
2. `output/work/需求单.md`(题目、范围、边界)
3. `output/work/文献详细列表.md`(**唯一可引用文献**)
4. `$SKILL/references/writing-rules.md`

## 写作流程

### 1) 锁定研究范围
从需求单与 prompt 提取:研究主题与核心问题、研究对象与边界、关键概念、需要回答的问题链。

### 2) 文献分组(按主题任选/组合)
- A 按研究主题分组(多维度研究):3–5 个主题类别;
- B 按研究演进分组(时间脉络明显):早期基础 → 方法演进 → 当前前沿;
- C 理论-方法-应用分组(应用型研究);
- D 按问题链分组(问题导向):问题识别 → 成因 → 方案 → 评估。
分组原则:每组至少 2–3 篇;组内逻辑连贯;某组不足则合并或换策略。

### 3) 结构(经典 4–6 段,按学科灵活)
1. 研究背景与问题提出(引 1–2 篇代表性文献);
2. 理论基础与概念界定(视需要);
3. 研究现状综述(核心,可拆 2–3 子段,按分组展开,每个论点都有 `[n]` 支撑);
4. 研究述评(共识/分歧/空白,批判性分析,不做简单罗列);
5. 研究启示与本文切入点(为后续章节过渡)。

理工科侧重"方法-应用-创新",社科侧重"理论-实证-述评"。

### 4) 引用规则(必须)
- 只允许引用 `文献详细列表.md` 中的编号,禁止空引用/装饰性引用;
- 引用序号按**首次出现顺序**从低到高:第一次出现为 [1],依此类推;同一文献多次引用沿用首现编号;文末列表排序与正文出现顺序一致。

## 质量自检(输出前)

- 证据链闭环:观点 → 引用 → 分析 → 结论;
- 每段一个主题,逻辑递进,与后续大纲章节可映射;
- 无 AI 腔(黑名单见 writing-rules:"综上所述""值得注意的是"等);
- 字数符合 prompt 要求(±10% 容差)。

## 约束

严禁编造文献/数据/观点;紧扣主题不泛化;只新增 `文献综述.md`,不改不删其他文件。
