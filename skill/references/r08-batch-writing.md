# r08 逐章批次写作

对应流水线步骤 8。按 `output/work/thesis_writing_plan.md` 依次产出 `output/work/正文_Batch1.md` … `正文_BatchN.md`。**每个批次开始前必须加载 `output/work/prompt.md`。**

## 批次循环(每批固定四步)

1. **承接加载**:第 2 批起,先读上一批末段 + 上一批"批次承接摘要";
2. **写作**:按该批的章节、字数、要点策略写作,遵循 prompt 与 writing-rules(真人口吻、反 AI 腔);引用只能用 `文献详细列表.md` 编号;数据只用 `案例与数据文档.md`(待核验数据照标注写入);
3. **落盘 + 承接摘要**:写入 `正文_BatchN.md`,末尾附:
   ```markdown
   ---

   ## 批次承接摘要
   - (3–5 句:本批写了什么、结论口径、下一批需要承接的线索与术语)
   ```
4. **硬校验(不过不放行)**:
   ```bash
   python3 "$SKILL/scripts/批次守护工具/verify_batches.py" \
     --plan output/work/thesis_writing_plan.md \
     --workdir output/work \
     --strict
   ```
   失败 → 补齐缺失内容/字数后重跑;**同一批重写最多 2 次,仍失败 → 停止问人**(报告失败原因与本批现状)。

## 图表占位符规范(写作时同步埋点)

需要图表的位置,独占一行,使用统一格式:

```markdown
> [插入图X-X:图表标题]
> [插入表X-X:表格标题]
```

- 序号按"章-序"连续(图2-1、图2-2…;表3-1…),标题具体明确;
- 禁用形式:`![图1](xxx)`、`[图表占位符 #1: …]`、纯文本"图1 xxx";
- 每个占位符在正文邻近段落必须已有对应的数据描述(数据来自案例与数据文档);
- 系统先行项目需要系统截图处,用 `> [插入图X-X:XX页面运行截图]`,后续生成截图引导占位。

## 写作纪律

- 不写废话、不灌水:扩写必须"有理有据、与主题强相关、结构一致";
- 术语、变量名、缩写全文统一(以后批服从前批);
- 严禁引入文献列表与案例文档之外的事实;
- 每批只新增自己的 `正文_BatchN.md`,不改其他文件。

全部批次(含摘要批次)完成并通过校验后,进入 r09 合并。
