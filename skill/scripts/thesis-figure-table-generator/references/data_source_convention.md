# 案例与数据文档中「数据来源」约定

本技能从「案例与数据文档」中解析或引用数据来源时，建议遵循以下约定，便于与正文占位符、图表规格清单对齐。

## 文档结构建议

- 按章节或模块组织（如 2.3 功能与界面、2.4 测试用例、2.5 技术栈与模块）。
- 每个与图表相关的小节可包含：
  - **数据说明**：指标含义、单位、口径。
  - **数据位置**：若来自文件，写明相对路径或可解析的路径（如 `system/runs/.../results.csv`）。
  - **设计要点**：图中应体现的要素（如流程图节点、架构层级、表格列）。

## 与占位符的对应

- 正文占位符中的「数据来源」描述（如 `数据来源: 第四章 4.1 节架构描述`）可与案例与数据文档的章节号对应，便于 `build_spec_from_doc` 自动或半自动补全 `data_source`、`data_path`、`options`。
- 若案例与数据文档中写明「真实数据：基于 xxx 文件」，则规格中应设置 `data_path`，生成器从该路径读取。

## 路径约定

- `data_path` 在规格中可为相对路径，相对于运行时的 `data_root`（项目根或指定目录）。
- 技能脚本应支持通过 `--data-root` 指定项目根，以便解析如 `system/runs/.../results.csv` 的路径。
