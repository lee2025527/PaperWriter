# 文献检索工具 V5.0 使用指南

**版本**: v5.0
**发布日期**: 2025-01-21
**升级重点**: 智能成本优化 + 质量优先筛选

---

## 📋 快速对比: V4 vs V5

| 特性 | V4.0 | V5.0 | 改进 |
|------|------|------|------|
| **API 成本** | 固定调用 | 智能调用 | 节省 30-50% |
| **质量控制** | 无质量筛选 | >= 60 分筛选 | 质量显著提升 |
| **相关搜索** | 忽略 | 自动利用 | 覆盖面扩大 |
| **停止机制** | 固定逻辑 | 多维智能 | 更精准高效 |
| **默认行为** | 目标 18 篇 | 无目标模式 | 成本更低 |

## 🎯 核心改进

### 1. API 成本优化

**V4.0 问题**:
```python
# 固定调用 2 轮，每轮期望 20 条
for round in range(2):
    papers = api_call(num=20)  # 即使返回 15 条也继续
    if len(papers) < 20:        # 不足 20 才停止
        break
```

**V5.0 改进**:
```python
# 智能决策，基于质量和数量
for round in range(3):  # 最多 3 轮保护
    papers = api_call(num=20)  # 请求最多，接受任意返回
    if len(papers) == 0:       # 0 结果立即停止
        break
    qualified = filter_by_quality(papers)
    if should_stop(qualified, target):  # 智能判断
        break
```

**成本节省示例**:
- 场景 1: 第 1 轮返回 20 条，18 条高质量（平均 80 分）
  - V4.0: 仍调用第 2 轮 → 2 次 API
  - V5.0: 检测到"数量达标+质量优秀" → 1 次 API
  - **节省**: 50%

- 场景 2: 无目标模式
  - V4.0: 默认调用 2 次
  - V5.0: 默认调用 1 次
  - **节省**: 50%

### 2. 质量优先筛选

**V5.0 质量评分公式**:
```python
quality_score = (
    year_score * 0.3 +        # 年份: 越新越好
    citation_score * 0.5 +    # 引用: 越多越好
    relevance_score * 0.2     # 相关性: 标题匹配
)

# 默认阈值: >= 60 分
# 优秀阈值: >= 75 分
```

**筛选流程**:
```
原始结果 (假设 20 条)
↓
质量评分 (0-100 分)
↓
筛选 >= 60 分 (假设剩 15 条)
↓
按分数降序排序
↓
返回前 N 条 (或全部)
```

### 3. 相关搜索利用

**V4.0**: 浪费 SerpAPI 免费提供的 `related_searches` 数据

**V5.0**: 自动利用相关查询扩展搜索
```
原始查询: "machine learning"
API 返回相关搜索: ["deep learning", "neural networks", "AI"]

V5.0 自动:
1. 搜索 "machine learning" → 15 条
2. 搜索 "deep learning" → 8 条 (最多取 1 个相关查询)
3. 合并到全局池: 23 条
4. 质量筛选: 取 >= 60 分的
5. 排序返回: 按质量降序

成本: 2 次 API (与搜索 2 个关键词相同)
收益: 获得更多相关文献
```

## 🚀 快速开始

### 基础用法

#### 1. 目标模式（指定文献数量）

```bash
python literature_search_optimized_v5.py \
  "人工智能在医疗诊断中的应用" \
  "人工智能,医疗诊断,深度学习" \
  "计算机科学与技术" \
  "人工智能" \
  18 \
  --output medical_ai
```

**行为**:
- 目标: 18 篇文献
- 质量阈值: >= 60 分
- 最多 3 轮 API 调用
- 达标且质量优秀时提前停止
- 利用相关搜索扩展

#### 2. 无目标模式（尽可能多但控制成本）

```bash
python literature_search_optimized_v5.py \
  "人工智能在医疗诊断中的应用" \
  "人工智能,医疗诊断,深度学习" \
  "计算机科学与技术" \
  "人工智能" \
  0 \
  --output medical_ai
```

**行为**:
- 目标: 无（0 表示无目标）
- 默认调用 1 次 API
- 返回所有 >= 60 分的文献
- 不限制数量

### 高级用法

#### 1. 调整质量阈值

```bash
# 更高质量要求 (70 分)
python literature_search_optimized_v5.py \
  "题目" "关键词" "专业" "方向" \
  18 \
  --min-score 70 \
  --output output
```

**适用场景**: 需要高质量核心文献

#### 2. 限制搜索轮数

```bash
# 最多 2 轮
python literature_search_optimized_v5.py \
  "题目" "关键词" "专业" "方向" \
  18 \
  --max-rounds 2 \
  --output output
```

**适用场景**: 控制成本上限

#### 3. 无目标时增加调用

```bash
# 无目标但调用 2 次
python literature_search_optimized_v5.py \
  "题目" "关键词" "专业" "方向" \
  0 \
  --no-target-rounds 2 \
  --output output
```

**适用场景**: 需要更多文献但无固定目标

#### 4. 禁用相关搜索

```bash
python literature_search_optimized_v5.py \
  "题目" "关键词" "专业" "方向" \
  18 \
  --no-related \
  --output output
```

**适用场景**: 仅搜索原始查询，不扩展

#### 5. 组合参数

```bash
# 高质量 + 限制轮数 + 禁用相关搜索
python literature_search_optimized_v5.py \
  "题目" "关键词" "专业" "方向" \
  18 \
  --min-score 70 \
  --max-rounds 2 \
  --no-related \
  --output output
```

## 📊 参数详解

### 必填参数

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `topic` | 字符串 | 论文题目 | "人工智能在医疗中的应用" |
| `keywords` | 字符串 | 关键词（逗号分隔） | "人工智能,医疗,深度学习" |
| `major` | 字符串 | 专业领域 | "计算机科学与技术" |
| `direction` | 字符串 | 研究方向 | "人工智能" |
| `max_results` | 整数 | 目标数量（0=无目标） | 18 或 0 |

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--output` | 字符串 | - | 输出文件前缀 |
| `--serpapi-key` | 字符串 | 环境变量 | SerpAPI 密钥 |
| `--hl` | 字符串 | 自动 | 语言代码 (en/zh-CN) |
| `--ca-bundle` | 字符串 | - | CA 证书路径 |
| `--min-score` | 整数 | 60 | 最低质量分数 (0-100) |
| `--max-rounds` | 整数 | 3 | 目标模式最大轮数 |
| `--no-target-rounds` | 整数 | 1 | 无目标模式调用次数 |
| `--num-per-call` | 整数 | 20 | 每次请求最大数 (SerpAPI 限制 20) |
| `--no-related` | 标志 | False | 禁用相关搜索 |

## 🔍 智能停止逻辑

### 目标模式 (max_results > 0)

**停止条件**:
1. **0 结果**: 本轮返回 0 条 → 立即停止并提示
2. **质量优秀**: 达标且平均分 >= 75 → 停止
3. **质量良好**: 接近达标(90%)且高质量占比 >= 80% → 停止
4. **轮数上限**: 达到最大轮数(默认 3) → 停止

**示例流程**:
```
目标: 18 篇, 质量阈值: 60

第 1 轮:
  API 返回: 20 条
  质量筛选: 18 条 >= 60 分
  平均分: 80 分
  判断: ✅ 达标且质量优秀
  操作: 停止搜索，返回 18 条

---

目标: 18 篇, 质量阈值: 60

第 1 轮:
  API 返回: 20 条
  质量筛选: 12 条 >= 60 分
  平均分: 70 分
  判断: ❌ 未达标，继续

第 2 轮:
  API 返回: 15 条
  累计筛选: 25 条 >= 60 分
  平均分: 73 分
  判断: ✅ 达标且质量良好
  操作: 停止搜索，返回前 18 条

---

目标: 18 篇, 质量阈值: 60

第 1 轮: 10 条合格
第 2 轮: 8 条合格 (累计 18)
第 3 轮: 5 条合格 (累计 23)
  判断: ⏹️ 达到最大轮数
  操作: 返回前 18 条高质量文献
```

### 无目标模式 (max_results = 0)

**停止条件**:
1. **0 结果**: 本轮返回 0 条 → 立即停止并提示
2. **完成轮数**: 完成指定轮数(默认 1) → 停止

**示例流程**:
```
无目标, 轮数: 1

第 1 轮:
  API 返回: 20 条
  质量筛选: 15 条 >= 60 分
  操作: 返回全部 15 条

---

无目标, 轮数: 2

第 1 轮: 15 条
第 2 轮: 12 条 (累计 27)
  操作: 返回全部 27 条，按质量排序
```

## ⚠️ 注意事项

### 1. 向后兼容性

- ✅ JSON 格式完全兼容
- ✅ 后续步骤（Step 2/3）无需修改
- ✅ 可独立使用或通过 Pipeline

### 2. 参数变更

- `max_results` 默认值从 18 改为 0
- 如需旧行为，显式指定 `--max 18`

### 3. 质量分数理解

- 60 分是综合评分，不是绝对标准
- 可根据实际效果调整阈值
- 冷门主题可适当降低

### 4. API 限制

- SerpAPI 限制每次最多 20 条
- `--num-per-call` 不应超过 20
- 相关搜索也算独立调用

## 🔧 故障排查

### 问题 1: 0 结果停止

**现象**:
```
⚠️ 本轮未获取到任何结果
➡️ 可能原因：查询过于具体或无相关文献
```

**解决**:
1. 检查关键词是否过于冷门
2. 尝试更通用的术语
3. 尝试英文关键词
4. 检查 SerpAPI 配额是否用完

### 问题 2: 质量分数都偏低

**现象**: 筛选后结果很少或为空

**解决**:
1. 降低 `--min-score` (如改为 50)
2. 增加 `--max-rounds` (如改为 5)
3. 检查关键词是否准确
4. 尝试启用 `--no-related` 避免扩展搜索

### 问题 3: 3 轮后仍未达标

**现象**:
```
⏹️ 达到最大轮数(3)
✅ 返回 16 条合格文献 (目标 18)
```

**解决**:
1. 这是正常保护机制
2. 已返回最高质量的可用结果
3. 如需更多，提高 `--max-rounds`
4. 或降低 `--min-score`
