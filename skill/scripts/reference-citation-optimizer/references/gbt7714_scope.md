# GB/T 7714 与本技能适用范围

## 标准简述

GB/T 7714-2015《信息与文献 参考文献著录规则》规定两种主要标注体系：

1. **顺序编码制**：按引文在正文中出现的顺序用数字标注；参考文献表按引用序号排列。文中常见形式为 `[1]`、`[2]` 或 `1`、`2` 等。
2. **著者-出版年制**：采用著者与出版年标注；参考文献表按著者字顺和出版年排序。文中常见形式为 `(作者, 年份)`。

## 本技能适用范围

- **仅处理顺序编码制**：对文中数字序号引用与文末按序号排列的参考文献列表进行「序号重排」与「同处升序」优化。
- **不处理著者-出版年制**：若文档主要为 (作者, 年份) 形式，本技能会检测并提示，不执行重排。

## 格式沿用

- 正文引用形态（纯文本 `[n]` 或 Word REF 域）保持不变，仅修改数字。
- 文末列表条目前缀自动识别并沿用，例如：`[1]`、`[1].`、`1.`、`1 ` 等，只替换编号部分，不改变标点与空格风格。
