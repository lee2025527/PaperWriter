# 数据生成工具使用说明

本工具用于在客户未提供真实数据且允许模拟时，生成问卷、实验、案例、访谈数据的标准化数据包，供正文写作使用。

## 1. 支持范围
- **survey**：问卷/量表数据
- **experiment**：实验或干预数据（支持分组与可选时间点）
- **case**：案例材料（结构化案例）
- **interview**：访谈主题与摘录

> 注意：如 `data_allowed=false`，工具将直接报错并停止。

## 2. 输入
- 数据需求规格（JSON）：
  - 模板：`scripts/数据生成工具/templates/data_requirements_template.json`
  - 示例：`scripts/数据生成工具/templates/*.json`

## 3. 输出（默认）
输出目录：`output/work/data/`
- `raw.csv`：原始数据
- `clean.csv`：清洗数据（缺失值填补）
- `data_dictionary.md`：字段解释/量表说明
- `data_summary.md`：描述性统计摘要
- `provenance.md`：生成规则与参数说明

按类型附加：
- survey：`scale_scoring.md`
- experiment：`group_stats.csv`
- case：`case_profiles.md`
- interview：`themes.md`

## 4. 使用方法

```bash
python3 scripts/数据生成工具/generate_data.py \
  --spec scripts/数据生成工具/templates/data_requirements_template.json \
  --out output/work/data \
  --seed 42
```

## 5. 规格文件要点
- `project.data_allowed` 必须为 `true`
- `data_spec.type` 必须为 `survey/experiment/case/interview`
- `variables` 用于 survey/experiment，需定义 `name/type/min/max/mean/std`
- `data_spec.groups` 用于 experiment
- `case_template` / `interview_template` 用于案例与访谈

## 6. 写作前置规则
- 生成数据后先检查 `data_summary.md` 与 `provenance.md`
- 未通过审核不得进入正文写作
